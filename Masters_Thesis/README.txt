This template was originally created in May 2022 and last updated in January 2024  by Samuel A. Myers.
It was designed to match the guidelines as listed at
https://grad.arizona.edu/gsas/dissertations-theses/dissertation-and-thesis-formatting-guides
and
https://arizona.app.box.com/v/grad-gsas-dissformat

Please note that this is a much simplified version of a longstanding dissertation template.
This simplifcation was done to make the template easier to work with and to take advantage
of the relaxed thesis guidelines of recent years.

List of files included:
bibliography.bib		An example bibliography for use with natbib
dissertationtemplate.tex	The main tex file. See comments at top of file for more info
dissertationtemplate.pdf	The compiled tex file
figure.eps			An example eps figure
includechapter.tex		An example chapter that can be input into the main file
signed_approval_page.pdf	An example signed approval page (not actually signed)

More comments and acknowledgments can be found at the top of dissertationtemplate.tex
